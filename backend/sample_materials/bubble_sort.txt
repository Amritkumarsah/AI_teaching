# CHAPTER 3: SORTING ALGORITHMS — BUBBLE SORT

## 3.1 What is Bubble Sort?
Bubble Sort is a simple comparison-based sorting algorithm. It works by repeatedly stepping through the list to be sorted, comparing adjacent elements and swapping them if they are in the wrong order. The pass through the list is repeated until no swaps are needed, indicating that the list is sorted.

The algorithm gets its name because smaller elements "bubble" to the top (or larger elements bubble to the end) of the list with each iteration, like air bubbles rising in water.

## 3.2 Step-by-Step Algorithm
For an array of n elements:
1. Outer Loop: Runs from pass = 0 to n - 1.
2. Inner Loop: Compares adjacent elements arr[j] and arr[j+1] from j = 0 to n - pass - 1.
3. If arr[j] > arr[j+1], swap them.
4. Optimization: If in any pass no swaps occurred, the array is already sorted and we break early!

Python Implementation:
```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr
```

## 3.3 Complexity Analysis
- Best Case Time Complexity: O(n) when array is already sorted (with swap flag).
- Worst Case Time Complexity: O(n^2) when array is reverse sorted.
- Average Case Time Complexity: O(n^2).
- Space Complexity: O(1) auxiliary space (In-place sorting algorithm).
- Stability: Stable algorithm (does not change relative order of elements with equal keys).
