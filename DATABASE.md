# AI Teacher — Database Schema & Architecture

> **Primary Datastore**: MongoDB (via Mongoose ODM)  
> **Design Strategy**: Document-oriented schemas with embedded sub-documents for fast atomic retrieval of structured lesson plans, interactive state sessions, and visual configurations.

---

## 1. Entity-Relationship Overview

```text
       ┌──────────────┐
       │    User      │
       └──────┬───────┘
              │ 1:1
              ├───► StudentProfile
              │ 1:1
              ├───► LearningProgress
              │ 1:N
              ├───► Documents ──► (1:N) DocumentChunks
              │ 1:N
              ├───► Lessons ────► (1:N) LessonSessions ──► (1:N) CheckpointAnswers
              │ 1:N
              ├───► Assessments ─► (1:1) AssessmentResults
              │ 1:N
              ├───► ConceptMastery (Weak / Strong Concepts)
              │ 1:N
              └───► VideoJobs / VoiceSessions / AuditLogs
```

## 2. Core Collections & Schema Definitions

### 1. `users`
Identity and credentials.
```typescript
{
  _id: ObjectId,
  name: { type: String, required: true },
  email: { type: String, required: true, unique: true },
  password: { type: String, required: true }, // Bcrypt hash
  role: { type: String, enum: ['STUDENT', 'TEACHER', 'ADMIN'], default: 'STUDENT' },
  isVerified: { type: Boolean, default: false },
  createdAt: Date,
  updatedAt: Date
}
```
* **Indexes**: `{ email: 1 }` (unique), `{ role: 1 }`.

### 2. `student_profiles`
Student onboarding preferences and cognitive preferences.
```typescript
{
  _id: ObjectId,
  userId: { type: ObjectId, ref: 'User', required: true, unique: true },
  educationLevel: { type: String, enum: ['beginner', 'intermediate', 'undergraduate', 'advanced'] },
  preferredLanguage: { type: String, default: 'en' },
  learningGoal: { type: String, enum: ['exam_prep', 'concept_mastery', 'quick_revision'] },
  teachingStyle: { type: String, enum: ['intuitive', 'rigorous', 'visual'] },
  availableStudyTimeMinutes: { type: Number, default: 20 },
  difficultyPreference: { type: String, default: 'medium' }
}
```
* **Indexes**: `{ userId: 1 }` (unique).

### 3. `documents`
Uploaded educational files.
```typescript
{
  _id: ObjectId,
  userId: { type: ObjectId, ref: 'User', required: true },
  filename: String,
  originalName: String,
  mimeType: String,
  fileSizeBytes: Number,
  filePath: String,
  pageCount: Number,
  isProcessed: { type: Boolean, default: false },
  chunkCount: Number
}
```
* **Indexes**: `{ userId: 1 }`, `{ isProcessed: 1 }`.

### 4. `document_chunks`
Semantic sections for RAG.
```typescript
{
  _id: ObjectId,
  documentId: { type: ObjectId, ref: 'Document', required: true },
  chunkIndex: Number,
  pageNumber: Number,
  chapter: String,
  section: String,
  text: String,
  tokensCount: Number,
  keywords: [String]
}
```
* **Indexes**:
  - Compound: `{ documentId: 1, chunkIndex: 1 }` (unique)
  - Text: `{ text: 'text', section: 'text', chapter: 'text' }`

### 5. `lessons`
Structured lesson plans generated by the AI Planner.
```typescript
{
  _id: ObjectId,
  userId: { type: ObjectId, ref: 'User', required: true },
  title: String,
  topic: String,
  documentId: { type: ObjectId, ref: 'Document' },
  targetDurationMinutes: Number,
  difficulty: String,
  language: String,
  teachingStyle: String,
  objectives: [String],
  prerequisites: [String],
  sections: [LessonSectionSchema],
  createdAt: Date
}
```
* **Indexes**: `{ userId: 1, createdAt: -1 }`, `{ topic: 1 }`.

### 6. `lesson_sessions`
Interactive teaching state machine tracking.
```typescript
{
  _id: ObjectId,
  userId: { type: ObjectId, ref: 'User', required: true },
  lessonId: { type: ObjectId, ref: 'Lesson', required: true },
  state: {
    type: String,
    enum: [
      'INTRODUCTION', 'EXPLANATION', 'DEMONSTRATION',
      'CHECK_UNDERSTANDING', 'EVALUATE', 'ADAPT',
      'REMEDIATION', 'NEXT_CONCEPT', 'FINAL_REVIEW'
    ]
  },
  currentSectionIndex: Number,
  interactionHistory: [InteractionEntrySchema],
  masteryScore: Number,
  language: String,
  difficulty: String
}
```
* **Indexes**: `{ userId: 1, lessonId: 1 }`, `{ state: 1 }`.

### 7. `concept_mastery`
Persistent tracking of student strengths and diagnosed misconceptions.
```typescript
{
  _id: ObjectId,
  userId: { type: ObjectId, ref: 'User', required: true },
  concept: { type: String, required: true },
  masteryScore: { type: Number, min: 0, max: 100 },
  attemptsCount: Number,
  correctCount: Number,
  diagnosedMisconceptions: [String],
  lastStudiedAt: Date
}
```
* **Indexes**: `{ userId: 1, concept: 1 }` (unique compound index), `{ userId: 1, masteryScore: 1 }`.

### 8. `video_jobs`
Asynchronous multimedia rendering queue.
```typescript
{
  _id: ObjectId,
  userId: { type: ObjectId, ref: 'User', required: true },
  lessonId: { type: ObjectId, ref: 'Lesson', required: true },
  status: { type: String, enum: ['QUEUED', 'PROCESSING', 'COMPLETED', 'FAILED'] },
  progress: Number,
  scenesCount: Number,
  videoUrl: String,
  errorMessage: String,
  createdAt: Date,
  completedAt: Date
}
```
* **Indexes**: `{ userId: 1, createdAt: -1 }`, `{ status: 1 }`.

---

## 3. Database Security & Least Privilege

* **Authentication**: Enforces SCRAM-SHA-256 in MongoDB Atlas with TLS 1.3 encryption in transit.
* **Role Privileges**: Application user is granted only `readWrite` access to the `ai_teacher` database.
* **Automated Migrations**: Mongoose schemas manage index synchronization automatically at application startup.
