# AI Teacher — Database Architecture & Schema Specification

The data layer is built on **MongoDB** using Mongoose schemas. MongoDB provides native nested BSON storage, which is required for pedagogical lesson trees (sections, checkpoints, LaTeX equations, and vector diagrams) without expensive multi-table joins.

---

## 1. Entity-Relationship Overview

```text
       ┌──────────────┐
       │    User      │
       └──────┬───────┘
              │ 1:1
              ├───► StudentProfile
              │ 1:1
              ├───► LearningProgress
              │ 1:N
              ├───► Documents ──► (1:N) DocumentChunks
              │ 1:N
              ├───► Lessons ────► (1:N) LessonSessions ──► (1:N) Answers
              │ 1:N
              ├───► Assessments ─► (1:1) AssessmentResults
              │ 1:N
              ├───► WeakConcepts / StrongConcepts
              │ 1:N
              └───► VideoJobs / VoiceSessions / AuditLogs
```

## 2. Core Collections Schema & Indexes (17 Collections)

### 1. `users`
* **Purpose**: Primary identity and authentication store.
* **Fields**: `_id`, `name` (String), `email` (String, Unique), `password` (String, Hashed), `role` (Enum: `'STUDENT' | 'TEACHER' | 'ADMIN'`), `googleId` (String, Optional), `isVerified` (Boolean), `createdAt`, `updatedAt`.
* **Indexes**: `{ email: 1 }` (Unique), `{ role: 1 }`.

### 2. `student_profiles`
* **Purpose**: Onboarding preferences, cognitive level, and pedagogical style.
* **Fields**: `_id`, `userId` (Ref: User), `educationLevel` (String: `'beginner' | 'intermediate' | 'undergraduate'`), `preferredLanguage` (String: `'en' | 'hi' | 'hinglish' | 'ta' | 'es'`), `learningGoal` (String: `'exam_prep' | 'concept_mastery'`), `teachingStyle` (String: `'intuitive' | 'rigorous' | 'visual'`), `availableStudyTimeMinutes` (Number), `difficultyPreference` (String).
* **Indexes**: `{ userId: 1 }` (Unique).

### 3. `documents`
* **Purpose**: Metadata of uploaded textbooks and lecture materials.
* **Fields**: `_id`, `userId` (Ref: User), `filename` (String), `originalName` (String), `mimeType` (String), `fileSizeBytes` (Number), `filePath` (String), `pageCount` (Number), `isProcessed` (Boolean).
* **Indexes**: `{ userId: 1 }`, `{ isProcessed: 1 }`.

### 4. `document_chunks`
* **Purpose**: Semantic text segments and vector index coordinates for RAG.
* **Fields**: `_id`, `documentId` (Ref: Document), `chunkIndex` (Number), `pageNumber` (Number), `chapter` (String), `section` (String), `text` (String), `tokensCount` (Number), `keywords` ([String]), `embedding` ([Number]).
* **Indexes**: `{ documentId: 1, chunkIndex: 1 }` (Compound), `{ documentId: 1, pageNumber: 1 }`.

### 5. `lessons`
* **Purpose**: Structured pedagogical lesson plans generated by the AI Planner.
* **Fields**: `_id`, `userId` (Ref: User), `title` (String), `topic` (String), `documentId` (Ref: Document, Optional), `targetDurationMinutes` (Number), `actualPlannedMinutes` (Number), `difficulty` (String), `language` (String), `teachingStyle` (String), `objectives` ([String]), `prerequisites` ([String]), `sections` ([LessonSectionSchema]), `assessmentQuestions` ([QuestionSchema]).
* **Indexes**: `{ userId: 1, createdAt: -1 }`, `{ topic: 1 }`.

### 6. `lesson_sessions`
* **Purpose**: Live state machine session tracker during interactive teaching.
* **Fields**: `_id`, `userId` (Ref: User), `lessonId` (Ref: Lesson), `currentState` (Enum: `'INTRODUCTION' | 'EXPLANATION' | 'DEMONSTRATION' | 'QUESTION' | 'ADAPTIVE_REMEDIATION' | 'COMPLETED'`), `currentSectionIndex` (Number), `currentCheckpointIndex` (Number), `activeRemediation` (Mixed), `answersGiven` ([AnswerSubschema]), `startedAt` (Date), `completedAt` (Date).
* **Indexes**: `{ userId: 1, lessonId: 1 }`, `{ currentState: 1 }`.

### 7. `questions`
* **Purpose**: Question bank for checkpoints and assessments.
* **Fields**: `_id`, `id` (String, Unique), `type` (Enum: `'MCQ' | 'SHORT_ANSWER' | 'CONCEPTUAL' | 'APPLICATION'`), `prompt` (String), `options` ([String]), `correctAnswer` (String), `rubricKeywords` ([String]), `explanation` (String), `misconceptionsMap` (Mixed: pattern triggers, diagnoses, analogies).
* **Indexes**: `{ id: 1 }` (Unique), `{ type: 1 }`.

### 8. `answers`
* **Purpose**: Persistent student responses and semantic rubric scores.
* **Fields**: `_id`, `userId` (Ref: User), `lessonSessionId` (Ref: LessonSession), `questionId` (String), `submittedAnswer` (String), `isCorrect` (Boolean), `score` (Number: 0-10), `feedback` (String), `misconceptionFound` (String, Optional).
* **Indexes**: `{ userId: 1, lessonSessionId: 1 }`, `{ isCorrect: 1 }`.

### 9. `assessments`
* **Purpose**: Final post-lesson quiz templates and passing rules.
* **Fields**: `_id`, `lessonId` (Ref: Lesson), `title` (String), `questions` ([Mixed]), `passingScorePercent` (Number: default 70).
* **Indexes**: `{ lessonId: 1 }`.

### 10. `assessment_results`
* **Purpose**: Comprehensive student report cards after quiz completion.
* **Fields**: `_id`, `userId` (Ref: User), `lessonId` (Ref: Lesson), `totalScore` (Number), `maxScore` (Number), `percentage` (Number), `strongConcepts` ([String]), `weakConcepts` ([String]), `misconceptionsFound` ([String]), `recommendedRevisionTopics` ([String]), `nextSuggestedTopic` (String).
* **Indexes**: `{ userId: 1, createdAt: -1 }`, `{ lessonId: 1 }`.

### 11. `learning_progress`
* **Purpose**: Long-term cumulative student analytics and study habits.
* **Fields**: `_id`, `userId` (Ref: User, Unique), `totalStudyTimeMinutes` (Number), `lessonsCompletedCount` (Number), `currentStreakDays` (Number), `lastStudyDate` (Date), `conceptMasteryMap` (Mixed), `weakConcepts` ([String]), `strongConcepts` ([String]).
* **Indexes**: `{ userId: 1 }` (Unique).

### 12. `weak_concepts`
* **Purpose**: Specific misconceptions flagged for remediation with mistake counters.
* **Fields**: `_id`, `userId` (Ref: User), `conceptName` (String), `failureCount` (Number), `lastEncountered` (Date), `resolved` (Boolean).
* **Indexes**: `{ userId: 1, resolved: 1 }`, `{ userId: 1, conceptName: 1 }`.

### 13. `strong_concepts`
* **Purpose**: Validated mastered concepts with high confidence.
* **Fields**: `_id`, `userId` (Ref: User), `conceptName` (String), `masteryScore` (Number: default 90), `successCount` (Number), `lastDemonstrated` (Date).
* **Indexes**: `{ userId: 1, conceptName: 1 }`.

### 14. `learning_paths`
* **Purpose**: Multi-module curriculum dependency tracks.
* **Fields**: `_id`, `userId` (Ref: User), `courseTitle` (String), `modules` ([{ title, description, isCompleted, estimatedMinutes, prerequisites: [String] }]).
* **Indexes**: `{ userId: 1, courseTitle: 1 }`.

### 15. `video_jobs`
* **Purpose**: Asynchronous MP4 video rendering queue.
* **Fields**: `_id`, `userId` (Ref: User), `lessonId` (Ref: Lesson), `status` (Enum: `'QUEUED' | 'PROCESSING' | 'COMPLETED' | 'FAILED'`), `progressPercent` (Number), `outputVideoUrl` (String), `errorMessage` (String), `completedAt` (Date).
* **Indexes**: `{ userId: 1 }`, `{ status: 1 }`.

### 16. `voice_sessions`
* **Purpose**: Cached neural speech audio outputs and viseme mouth animation timelines.
* **Fields**: `_id`, `userId` (Ref: User), `textInput` (String), `language` (String), `voiceName` (String), `audioDurationSeconds` (Number), `audioFileUrl` (String), `visemeTimings` ([{ timeMs, visemeId }]).
* **Indexes**: `{ userId: 1 }`.

### 17. `audit_logs`
* **Purpose**: Security telemetry, permission changes, and data deletions.
* **Fields**: `_id`, `userId` (Ref: User, Optional), `action` (String), `ipAddress` (String), `userAgent` (String), `details` (Mixed), `createdAt` (Date).
* **Indexes**: `{ action: 1 }`, `{ userId: 1, createdAt: -1 }`.
